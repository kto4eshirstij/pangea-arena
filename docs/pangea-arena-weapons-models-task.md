ветка `develop` → `feature/weapons-tier0`. Концепты — `docs/pangea-arena-weapons-concepts.md`
(уже на ноутбуке). Приёмы и слоты — `docs/abilities-tier0.md`.

## Принятые решения (04.11.2026)

1. Берём **все ★-варианты**: обмотки (кулаки), палица с голышом, копьё с кремнёвым листом +
   копьеметалка, плетёная праща + голыши + бола, тисовый лук + стрелы + огненная стрела + колчан,
   смоляной факел, круглый щит из шкуры. Взрывной прыжок — «удар о землю» (эффект, не модель).
2. Руки от 1-го лица — **3 комплекции**:
   - `small` — гном, полурослик, гоблин, фей;
   - `medium` — человек, эльф, дварф, орк, драконорождённый, тифлинг, фелар;
   - `large` — голиаф, тролль.

   Цвет кожи и мелкие детали (чешуя, когти, мех) — текстурой по народу, 13 штук.
3. Роспись охрой — **случайная из набора**: 4 варианта росписи на каждое оружие. Клиент выбирает
   вариант по номеру клиента в матче (стабильно на весь матч).
4. Модели собирает **Claude Code скриптами Blender** на ноутбуке (headless). Это low-poly
   первой версии, позже их можно заменить работой художника по тем же путям и тегам.

Правила: каждый этап — отдельный коммит `arena:`; ⛔ — стоп и вопрос; исходники (`.py`, `.blend`
не коммитить — генерируются) — под GPL в репо; ни одного ассета из OpenArena/Quake в итоговом паке.

## W1. Библиотека материалов и текстур (`tools/weapons/lib/`)

`materials.py` — процедурные материалы Blender (шумы Voronoi/Noise/Musgrave → base color, roughness,
bump) с запеканием в `.tga` 512×512:

| Материал | Вид |
|---|---|
| `flint` | серо-коричневый, голубоватые сколы-раковины, матовый с бликом на рёбрах |
| `obsidian` | (резерв для скинов) |
| `bone` | желтовато-белый, поры, тёмные трещины, затёртые края |
| `wood_ash`, `wood_yew` | светлый ясень с волокном / тис с красноватой сердцевиной |
| `wood_charred` | обугленный верх факела |
| `hide` | сыромятная шкура, неровный тон, края темнее |
| `leather_wrap` | обмотки с видимыми витками (текстура полос по UV-оси) |
| `sinew` | шнур, светло-янтарный |
| `river_stone` | гладкий голыш, 4 оттенка |
| `fur` | короткий мех (альфа-край не нужен, просто текстура) |
| `feather` | оперение, 2 цвета |
| `pitch` | смола: тёмная, глянцевая |

`ochre.py` — генератор росписи: поверх базовой текстуры 4 набора узоров (полосы, точки, отпечаток
ладони, зигзаг) охрой `#b5532a`, жёлтой охрой `#c99a3a` и сажей. Результат —
`<id>_paint1..4.tga`.

`bake.py` — общий запуск: UV smart project → bake diffuse/AO в одну текстуру → сохранить TGA
(24 бит, без RLE — ioq3 читает оба, но так проще).

## W2. Модели оружия (`tools/weapons/models/<id>.py`)

Масштаб: 1 единица Q3 ≈ 1 дюйм (человек 56 ед.); в Blender работать в сантиметрах ×0.3937.
Каждая модель — функция `build()` → объект(ы) + пустышки-теги. Ось вперёд — +X (как в Q3),
верх +Z, хват — в начале координат.

| id | Модель (концепт ★) | Треуг. мир | Теги |
|---|---|---|---|
| `fists` | только руки, ремни на костяшках, костяная пластинка | — | `tag_flash` у кулака |
| `club` | ясеневая рукоять 70 ед., голыш в расщепе, крест сухожилия, смола в щелях, темляк | ≤ 500 | `tag_weapon`, `tag_flash` у навершия |
| `spear` | древко 70 ед. (в масштабе Q3 укорочено ради кадра), кремнёвый лист, перья/мех под ним, обожжённая пятка | ≤ 450 | `tag_weapon`, `tag_flash` у острия |
| `atlatl` | дощечка с крючком и рукоятью «голова зверя» (левая рука) | ≤ 200 | `tag_weapon_l` |
| `sling` | два шнура, кожаный кармашек с дырочками, петля, кисточка; голыш в кармашке | ≤ 300 | `tag_flash` у кармашка |
| `bow` | тисовый длинный лук, кожаная рукоять, роговые накладки, тетива | ≤ 600 | `tag_weapon`, `tag_flash` на тетиве |
| `torch` | палка, расщеп с берестой и паклей, обугленный верх; пламя — отдельная поверхность `flame` (две скрещённые плоскости, шейдер) | ≤ 350 | `tag_flash` в пламени (точка света) |
| `shield` | ивовый обод Ø 24 ед., шкура, костяной умбон, ремень | ≤ 500 | `tag_weapon` (на левом предплечье) |

Снаряды и предметы:

| id | Что | Треуг. |
|---|---|---|
| `proj_stone1..4` | голыши разной формы | 40–80 |
| `proj_arrow`, `proj_arrow_fire` | тростник, кремнёвый листок, 3 пера; у огненной — пакля (+ шейдер огня) | ≤ 120 |
| `proj_spear` | = `spear` (мир) | — |
| `proj_bola` | три мешочка на ремнях звездой | ≤ 200 |
| `proj_brand` | головня (обрубок факела) | ≤ 150 |
| `proj_boulder` | валун голиафа | ≤ 150 |
| `item_quiver` | берестяной колчан с мехом и 5 оперениями | ≤ 300 |
| `item_stones` | кучка из 6 голышей | ≤ 300 |

## W3. Руки (`tools/weapons/hands/`)

- Три базовых меша кисти и предплечья до локтя: `small` (тонкие, короткие пальцы), `medium`, `large`
  (широкая ладонь, толстые пальцы, костяшки). ≤ 900 треуг. на пару рук. Пальцы — сегментами,
  без скелета.
- Позы хвата (статичные, по одной на категорию): `fist` (оба кулака), `club` (правая на рукояти),
  `spear` (правая сверху, левая впереди), `spear_atlatl`, `sling` (правая держит петлю, левая —
  голыш), `bow` (левая на рукояти, правая у тетивы), `torch`, `shield` (левая в ремне, правая
  кулаком), `rite` (ладони сложены чашей).

  Позы задаются поворотами сегментов пальцев в скрипте (таблица углов в `poses.py`).
- Текстуры кожи по народам: 13 `.tga` 256×512 по палитре народов (человек, эльф, дварф, гном,
  полурослик, орк, гоблин, голиаф, драконорождённый — чешуя, тифлинг, тролль — бородавки и
  сероватая кожа, фелар — короткий мех и когти, фей — светлая кожа с перламутром).

  Обмотки кулаков — отдельная поверхность `wraps`, одна для всех.
- Анимации удара, замаха и натяжения — **кодом** в cgame (сдвиг и поворот модели вида, как отдача
  оружия в `cg_weapons.c`), а не кадрами MD3. Модели статичные, по одному кадру.

## W4. Экспорт в MD3 и пак

- `tools/weapons/export.py` (запускается внутри Blender): для каждой модели — треугольники мира
  в системе Q3, UV, нормали, теги из пустышек `tag_*` → вызов MD3-писателя из `tools/md3/`
  (статический режим: 1 кадр, поверхности ≤ 999 вершин / ≤ 1999 треуг., обход по часовой).
- Раскладка в паке (`content/pangea/`):
  ```
  models/weapons2/<id>/<id>.md3            # мир и вид от 1-го лица
  models/weapons2/<id>/<id>_hand.md3       # только tag_weapon (позиция в руке персонажа)
  models/weapons2/<id>/<id>.tga, <id>_paint1..4.tga
  models/weapons2/<id>/<id>_paint1..4.skin # подмена текстуры поверхности
  models/hands/<build>/<pose>.md3          # small|medium|large × 9 поз
  models/hands/skin/<race>.tga             # 13 народов
  models/projectiles/<id>.md3
  icons/iconw_<id>.tga                     # 64×64, силуэт охрой на прозрачном (рендер Blender)
  scripts/pangea_weapons.shader            # пламя факела и огненной стрелы, тлеющие угли
  ```
- Шейдер пламени: две скрещённые плоскости, `animMap 15` по 8 кадрам языков пламени (кадры
  рендерит Blender в W4 — процедурный огонь на плоскости), `blendFunc add`, `deformVertexes wave`
  для дрожания.
- `tools/weapons/build_all.sh`: генерация → запекание → экспорт → сборка `arena-weapons-<sha8>.pk3`.

```bash
cd /home/gaskonec/muddev/pangea-arena
bash tools/weapons/build_all.sh            # ~5–15 мин на CPU
unzip -l content/build/arena-weapons-*.pk3 | tail -5
```

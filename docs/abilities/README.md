
# C7 — обряды (слот 8) и наследия народов (слот 9)

Ветка `feature/abilities-c7`, 2026-11-07. Цифры — мои (механики порога 0 на ноутбуке нет), все в `code/game/bg_pangea.c`.

- Народ и вера героя: `ps.persistant[PERS_PANGEA_KIN]` = народ | вера << 4; приходят из MUD
  (`players[].race`, `players[].faith`) через `g_pangea_races "ticket=race.faith"`; в строке игрока — `pr`, `pf`.
- У слотов 8–9 одна перезарядка на слот: и первый, и второй приём её запускают («один обряд на вдох»).
